================================================================================
                    ІНСТРУКЦІЯ З ВСТАНОВЛЕННЯ ТА РЕЖИМІВ РОБОТИ
================================================================================

Downloader підтримує два режими розгортання та збереження даних:
звичайний (встановлення в профіль користувача) та портативний (робота з USB-флешки).

--------------------------------------------------------------------------------
1. ЗВИЧАЙНИЙ РЕЖИМ (ТИПОВИЙ ДЛЯ РОБОЧОЇ СТАНЦІЇ)
--------------------------------------------------------------------------------

При встановленні через інсталятор (MSI) або звичайному запуску:
- Виконувані файли програми розміщуються у:
    %LOCALAPPDATA%\Programs\Downloader\
  (не потребує прав адміністратора чи UAC-ескалації).

- База завдань (SQLite) та налаштування швидкості/розкладу зберігаються у:
    %LOCALAPPDATA%\Downloader\tasks.db

- Налаштування теми графічного інтерфейсу зберігаються у:
    %LOCALAPPDATA%\Downloader\ui.json

- Маніфест Native Messaging Host для браузерів Chrome / Edge:
    %LOCALAPPDATA%\Downloader\nm\com.downloader.host.json

- Типова тека завантажених файлів:
    %USERPROFILE%\Downloads\

--------------------------------------------------------------------------------
2. ПОРТАТИВНИЙ РЕЖИМ (PORTABLE MODE НА ФЛЕШЦІ)
--------------------------------------------------------------------------------

Якщо ви носите Downloader на USB-флешці або запускаєте з окремого каталогу:
1. Створіть порожній файл з ім'ям `portable.txt` поруч із виконуваними
   файлами програми (поруч із downloader-core.exe, Downloader.Ui.exe, dl.exe).

2. За наявності маркера `portable.txt`:
   - База даних завдань та всі налаштування зберігаються у тій самій теці:
       <тека_програми>\tasks.db
   - Конфігурація теми вікна зберігається у:
       <тека_програми>\ui.json
   - Типова тека завантажень спрямовується у підкаталог:
       <тека_програми>\Downloads\

3. Програма не залишає слідів у %LOCALAPPDATA% та є повністю автономною.
   Для повернення до звичайного режиму достатньо видалити файл `portable.txt`.

--------------------------------------------------------------------------------
3. БРАУЗЕРНЕ РОЗШИРЕННЯ (CHROME / EDGE)
--------------------------------------------------------------------------------

Детальні інструкції щодо підключення браузерного перехоплювача завантажень,
збірки Native Messaging Host та встановлення .crx дивіться у:
    ext\INSTALL.txt
