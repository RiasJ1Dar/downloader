================================================================================
        ПІДКЛЮЧЕННЯ БРАУЗЕРНОГО РОЗШИРЕННЯ DOWNLOADER
================================================================================

Що робить розширення:

1. перехоплює завантаження (downloads.onCreated + cancel) і передає ядру
   адресу разом із cookies та referer;
2. знаходить потоки HLS (.m3u8) і DASH (.mpd) на сторінці — через
   webRequest і PerformanceObserver — і малює кнопку «Завантажити» над відео;
3. передає завдання через native messaging у downloader-nmhost, а той
   говорить із ядром через named pipe. Локального TCP-порту немає навмисно:
   порт на 127.0.0.1 відкритий будь-якій програмі на машині.

--------------------------------------------------------------------------------
КРОК 1. Зареєструвати native messaging host
--------------------------------------------------------------------------------

    cargo build -p downloader-nmhost
    target\debug\downloader-nmhost.exe --install

Створює маніфест у %LOCALAPPDATA%\Downloader\nm\com.downloader.host.json і
прописує шлях до нього:

    HKCU\Software\Google\Chrome\NativeMessagingHosts\com.downloader.host
    HKCU\Software\Chromium\...
    HKCU\Software\Microsoft\Edge\...
    HKCU\Software\BraveSoftware\Brave-Browser\...
    HKCU\Software\Vivaldi\...
    HKCU\Software\Opera Software\Opera Stable\...
    %APPDATA%\Mozilla\NativeMessagingHosts\com.downloader.host.json

⚠️ Кожен браузер читає СВОЮ гілку. Запис для Chrome не бачать ні Brave, ні
Vivaldi — тому пишемо в усі відомі одразу, навіть якщо браузера ще немає.

Розширення з магазину має інший ідентифікатор, ніж розпаковане. Щоб хост його
приймав, додайте ID при встановленні:

    downloader-nmhost.exe --install --allow-extension <ID з магазину>

Прапорець можна вказати кілька разів. ID з символом «@» іде у список Firefox,
решта — у список Chromium.

--------------------------------------------------------------------------------
КРОК 2. Поставити розширення
--------------------------------------------------------------------------------

Варіант А — розпакована тека (працює завжди, потрібен для розробки):

  Chrome     chrome://extensions
  Edge       edge://extensions
  Brave      brave://extensions
  Vivaldi    vivaldi://extensions
  Firefox    about:debugging#/runtime/this-firefox

  1. Увімкнути «Режим розробника» (у Firefox — «Тимчасово завантажити
     додаток»).
  2. «Завантажити розпаковане розширення» → тека ext\chrome
     (у Firefox вибрати файл ext\chrome\manifest.json).
  3. Звірити ідентифікатор із наведеним вище.

  ⚠️ У Chromium розпаковане розширення живе до перезапуску браузера без
  попереджень, але щоразу показує банер «Вимкніть розширення в режимі
  розробника». У Firefox тимчасовий додаток зникає після закриття браузера.

Варіант Б — файл .crx: НЕ ПРАЦЮЄ.

  Chrome з версії 67 відхиляє сторонні CRX із диска
  («CRX_REQUIRED_PROOF_MISSING»), і те саме роблять Edge, Brave і Vivaldi.
  Файл можна поставити лише через корпоративну політику
  (ExtensionInstallForcelist) або з магазину. Для щоденної роботи —
  варіант А, для роздачі людям — магазин.

Варіант В — магазин (основний шлях для користувачів):

  Firefox Add-ons  безкоштовно, AMO підписує пакет, ідентифікатор наш власний
  Chrome Web Store $5 одноразово, ідентифікатор призначає магазин — після
                   публікації додати його через --allow-extension (крок 1)

--------------------------------------------------------------------------------
КРОК 3. Перевірити на живому сайті
--------------------------------------------------------------------------------

1. Запустити ядро:

       cargo run -p downloader-core-service

2. Завантаження файлу: натиснути пряме посилання (.zip, .iso, .mp4).
   Браузер скасує власне завантаження, завдання з'явиться в Downloader
   із cookies і referer.

3. Потік: відкрити сторінку з відео. Над плеєром з'явиться кнопка
   «Завантажити».

4. Якщо нічого не відбувається — відкрити службову сторінку розширень,
   натиснути «service worker» (Chromium) або «Інспектувати» (Firefox) у
   картці Downloader і подивитися консоль. Повідомлення «Specified native
   messaging host not found» означає крок 1: або хост не зареєстровано, або
   ідентифікатор розширення не збігається зі списком у маніфесті.
