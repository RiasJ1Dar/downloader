# Журнал змін проєкту Downloader

Усі помітні зміни у проєкті Downloader документуються у цьому файлі.
Формат базується на Keep a Changelog (https://keepachangelog.com/),
і проєкт дотримується Semantic Versioning (https://semver.org/).

## [0.1.0] - 2026-09-15

### Додано (Unix experimental, теґ v0.1.0-unix)
- Повний стек на Linux і macOS: ядро (tray + IPC), CLI `dl`, Avalonia UI, nmhost.
- Автозапуск: systemd user unit `packaging/systemd/downloader-core.service` та
  LaunchAgent `packaging/macos/com.riasj1dar.downloader-core.plist`; підключає
  `packaging/install-unix.sh` (`systemctl --user enable --now` / `launchctl load`).
- Пакування без підпису: `build-unix-tarball.sh` (linux-x64, macos-arm64, macos-x64),
  `build-deb.sh` → `.deb`. AppImage / notarized `.dmg` немає.
- CI prerelease: `.github/workflows/release-unix.yml` на теґи `v*-unix`
  (ubuntu-latest + macos-latest). Windows `release.yml` лишається для `v*`;
  теґи `*-unix` пропускаються.

### Додано
- Багатопотоковий рушій завантаження (Rust core):
  - Сегментація файлу на паралельні частини з динамічним викраденням залишків (work stealing).
  - Надійне докачування (resume) з відстеженням стану та збереженням у .state файли.
  - Адаптивний буфер у пам'яті з періодичним скиданням на диск через fsync.
  - Перевірка цілісності розміру та контрольних сум SHA-256.
- Підтримка протоколів та джерел:
  - HTTP/HTTPS: підтримка Range-запитів, користувацьких заголовків (User-Agent, Referer, Cookie), авторизації (включаючи 401 з повтором) та HTTP/SOCKS5 проксі.
  - HLS VOD: вибір якості відео та аудіо, автоматичне розшифрування AES-128, зведення доріжок через FFmpeg.
  - DASH VOD: підтримка маніфестів MPD із SegmentTemplate та SegmentTimeline, вибір якості та об'єднання потоків через FFmpeg.
  - Зовнішні завантажувачі: механізм proto-external (JSON-RPC через stdin/stdout) та інтеграція yt-dlp для YouTube та інших платформ.
- Керування завантаженнями та іменовані черги:
  - Система іменованих черг із незалежними лімітами слотів, швидкості завантаження (RateLimiter) та вікнами розкладу (Schedule).
  - Спеціальна черга за замовчуванням (default), яку не можна видалити або перейменувати.
  - Безпечні післядії (вимкнення комп'ютера, сон, гібернація) із гарантією завершення всіх активних черг.
  - Команда переміщення завдань між чергами (dl move).
- Сервіс ядра та IPC:
  - Фоновий Windows-сервіс (core-service), що працює в системному треї.
  - IPC на базі JSON-RPC через Windows Named Pipe (\\.\pipe\downloader-ipc).
  - Сховище завдань SQLite з автоінкрементними міграціями схеми.
  - Автоматичне перехоплення підтримуваних посилань (включаючи m3u8 і mpd) з буфера обміну Windows.
- Консольний клієнт (CLI dl):
  - Повний набір команд: add, list, pause, resume, rm, move, queue, config, completions.
  - Підтримка списків URL (--list), очищення URL від сміття, генерація діапазонів чисел ([1-10]).
- Графічний інтерфейс користувача (Avalonia UI 12):
  - Повноцінний сучасний інтерфейс на C# / Avalonia 12 Fluent Design.
  - Панель керування завантаженнями, індикація швидкості, прогрес-бари сегментів.
  - Керування іменованими чергами: додавання, пауза, відновлення, видалення черг.
  - Вікно додавання завантаження з автоматичним зондуванням (probe) доступних якостей відео/аудіо.
  - Світла та темна теми оформлення, інтеграція з системним треєм ядра.
- Локалізація:
  - Повна локалізація українською (uk) та англійською (en) мовами через Fluent (FTL).
  - Автоматичне визначення системної мови або вибір у налаштуваннях.
  - Суворий мовний бар'єр: повна відсутність російськомовних локалей.
- Автономність та портативність:
  - Портативний режим за наявності маркерного файлу portable.txt поруч із виконуваним файлом: база даних SQLite, конфігурація та завантажені файли зберігаються в теці програми.
  - Звичайний режим зі збереженням даних у %LOCALAPPDATA%\Downloader.
- Браузерна інтеграція:
  - Розширення для Chrome та Edge (Manifest V3) із можливістю перехоплення посилань та медіапотоків зі сторінки.
  - Модуль Native Messaging Host (downloader-nmhost) для надійного зв'язку браузера з ядром.
- Інсталяція та реліз-пайплайн:
  - Складання двох варіантів MSI-пакетів через WiX Toolset 6.0.2: web-інсталятор та full-інсталятор із вбудованим LGPL FFmpeg.
  - Скрипт packaging/zibraty.ps1 з автозавантаженням FFmpeg та підрахунком контрольних сум у SHA256SUMS.txt.
  - Автоматизований GitHub Actions workflow (.github/workflows/release.yml) для створення чернеток релізів при публікації теґів v*.
