             ІНСТРУКЦІЯ З ПІДКЛЮЧЕННЯ БРАУЗЕРНОГО РОЗШИРЕННЯ DOWNLOADER
================================================================================

Розширення забезпечує:
1. Автоматичне перехоплення завантажень файлів (downloads.onCreated + cancel)
   з передачею посилань, cookies та referer до ядра Downloader.
2. Виявлення HLS (.m3u8) та DASH (.mpd) медіа-потоків на сторінках (через
   declarativeNetRequest, PerformanceObserver та кнопку «Завантажити» над відео).
3. Передачу завдань через Chrome Native Messaging до downloader-nmhost,
   який з'єднується з ядром через named pipe (без локальних відкритих TCP-портів).

Фіксований Extension ID: pionjhjgjaehkcpkidlblhonbejfdcdj

--------------------------------------------------------------------------------
КРОК 1. Збірка та реєстрація Native Messaging Host (downloader-nmhost)
--------------------------------------------------------------------------------
1. Зберіть виконуваний файл nmhost:
     cargo build -p downloader-nmhost

2. Запустіть встановлення маніфесту в систему:
     target\debug\downloader-nmhost.exe --install

   Це автоматично:
   - Створить маніфест com.downloader.host.json у:
     %LOCALAPPDATA%\Downloader\nm\com.downloader.host.json
   - Пропише шлях у реєстрі Windows для Chrome та Edge:
     HKCU\Software\Google\Chrome\NativeMessagingHosts\com.downloader.host
     HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.downloader.host

--------------------------------------------------------------------------------
КРОК 2. Встановлення розширення у Google Chrome / Microsoft Edge
--------------------------------------------------------------------------------

Варіант А. Режим розробника (рекомендовано для тестування та налагодження):
1. Відкрийте браузер і перейдіть за адресою:
     chrome://extensions  (для Chrome)
     edge://extensions    (для Edge)
2. Увімкніть перемикач «Режим розробника» (Developer mode) у верхньому правому кутку.
3. Натисніть кнопку «Завантажити розпаковане розширення» (Load unpacked).
4. Оберіть теку:
     D:\Downloader\ext\chrome
5. Переконайтеся, що ідентифікатор розширення:
     pionjhjgjaehkcpkidlblhonbejfdcdj

Варіант Б. Автоматизована збірка .crx (для дистрибуції та корпоративних політик):
1. Запустіть скрипт збірки CRX:
     powershell -ExecutionPolicy Bypass -File D:\Downloader\ext\build-crx.ps1
2. Буде створено файл D:\Downloader\ext\downloader.crx, підписаний стабільним ключем.
   Зверніть увагу: Chrome починаючи з версії 67 блокує прямий drag-and-drop сторонніх
   CRX-файлів з помилкою «CRX_REQUIRED_PROOF_MISSING». Для щоденної роботи та
   налагодження використовуйте Варіант А (розпаковане розширення). Для встановлення CRX
   на робочих станціях використовується групова політика ExtensionInstallForcelist
   або публікація у Chrome Web Store.

--------------------------------------------------------------------------------
КРОК 3. Перевірка роботи на живому сайті
--------------------------------------------------------------------------------
1. Запустіть ядро Downloader:
     cargo run -p downloader-core-service
   (або запустіть графічний застосунок / CLI).

2. Перевірка завантаження файлу:
   - Клікніть на будь-яке пряме посилання на завантаження (.zip, .iso, .exe, .mp4).
   - Chrome скасує внутрішнє завантаження.
   - Завдання негайно з'явиться в Downloader з правильними cookies та referer.

3. Перевірка перехоплення відеопотоку:
   - Відкрийте сторінку з відеоплеєром (наприклад, HLS/DASH або HTML5 відео).
   - У правому нижньому кутку плеєра з'явиться кнопка «Завантажити».
   - Натискання кнопки передає потік до ядра Downloader.

4. Перевірка логів native host у браузері:
   - На сторінці chrome://extensions натисніть «Фоновий режим: background.js»
     у картці Downloader, щоб відкрити DevTools фонового процесу.
   - При кожному кліку або завантаженні у консолі виводиться статус зв'язку
     з native host («Downloader завдання <ID>»).
